# JavaScript OOP & JSON Practice

A collection of JavaScript practice tasks focused on **Object-Oriented Programming (OOP)** and **JSON data handling**.

## 📚 Topics Covered

### Task 13.1 — User Management System

* JavaScript Classes
* Constructors
* Objects
* Class Methods
* `this` keyword
* Arrays of objects
* `forEach()`
* Conditional statements

### Task 13.2 — Working with JSON Data

* JSON strings
* `JSON.parse()`
* JavaScript objects and arrays
* Accessing object properties
* `forEach()`
* Template literals
* `JSON.stringify()`

## 🎯 Objective

The goal of these tasks is to strengthen JavaScript fundamentals by practicing how to create and manage objects, work with classes, and convert data between JSON and JavaScript objects.
